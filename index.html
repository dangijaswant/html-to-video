HTML → VIDEO

Frame-accurate HTML/CSS/GSAP capture to transparent WebM, lossless WebP, and ProRes MOV — built for overlays, not screen recordings.

Live demo + studio UI. HQ export uses HyperFrames + FFmpeg on your machine (same quality as the CLI) — preview works in the browser now.

Open live studio GitHub

Sample alpha WebM · studio UI is live below.

Pipeline

01

Author in HTML

Transparent background. Seekable GSAP timeline. No wall-clock animations.

02

Capture PNG frames

HyperFrames drives a virtual clock and dumps lossless RGBA frames.

03

Encode alpha outputs

FFmpeg → animated WebP (lossless), VP9 WebM, ProRes 4444 MOV.

Formats

WebM (VP9) Best for web overlays. Chrome / Firefox / Edge.
WebP Lossless animated image with alpha. Open in Chrome.
ProRes 4444 Editor master for Premiere, AE, CapCut.

Full engine (HQ export)

Use the live studio to edit & preview. For Export HQ, start the local engine once — the studio talks to 127.0.0.1:8787. 

git clone https://github.com/dangijaswant/html-to-video.git
cd html-to-video/engine
npm run studio

# keep engine running, then Export HQ from the live studio
# or open http://127.0.0.1:8787

CLI (same pipeline)

cd html-to-video/engine
npm run encode:hq

# outputs under engine/renders/
